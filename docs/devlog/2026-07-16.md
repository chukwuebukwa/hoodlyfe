# Development Log - 2026-07-16

## 00:23 CST - Zone- and Time-Aware Ambient Population

- Re-audited the pinned re3 and reVC zone, population, and traffic controllers. Their
  production pattern keeps spatial density, pedestrian mix, civilian vehicle weights, and
  ambient police share in zone data, then blends the day and night profiles before global
  population managers consume them.
- Added four original NOCK0 district profiles plus a fail-safe fallback. Each profile owns
  day/night pedestrian density, traffic density, ambient police share, and civilian vehicle
  weights. Police vehicles remain excluded from random traffic; wanted response continues
  through the pursuit allocator.
- Added a pure profile policy and a small authoritative profile controller. World time comes
  from the existing server clock. Actor-kind selection occurs only when a cold record enters
  live simulation, so active visible actors never change identity when the clock advances.
- Composed profiles beneath the existing multiplayer interest-cluster allocator and global
  40-pedestrian/24-traffic ceilings. A profile can reduce or rank local demand but cannot
  create per-player copies, steal another distant cluster's share, or bypass protected-state
  rules.
- Added bounded day/night convergence through the existing dematerialization budget. Only
  offscreen, streamable ambient actors can return to cold state; hot, occupied, hijacked,
  mission, damaged, burning, destroyed, combat, and otherwise pinned actors remain live.
- Extended F3 Population with authoritative world time, day blend, active-zone counts,
  profile-held candidates, and profile rebalances. Recorded the primary-source audit and
  clean-room adaptation in `ZONE_TIME_POPULATION_RESEARCH.md` and ADR 0016, and updated the
  architecture map, streaming research, and systemic gameplay roadmap.
- Kept the netcode boundary frozen. No prediction, reconciliation, interpolation, rewind,
  interaction-island, rollout, or shared movement/contact implementation changed.

## 02:24 CST - Authored Multi-Lane Passing and Conflict Geometry

- Audited pinned re3/reVC autopilot, route-lane, traffic speed, and weave behavior. The
  transferable production boundary is current/next lane state plus lane-constrained turn
  legality, with ordinary following kept separate from aggressive obstacle weaving.
- Promoted the completed population checkpoint to local `main` at the already-merged
  remote commit `9c54379`, then created and published
  `codex/systemic-gameplay-g2c-authored-lane-change`.
- Upgraded the district lane asset to schema version 2 with explicit lane spacing and two
  lanes per direction on seven validated corridors. Compiled nodes now retain lane index
  and count; junction connectors enforce inner-left, outer-right, and preserved straight
  lanes.
- Added pure lane-change admission for lead clearance, sampled road occupancy, target-lane
  front/rear relative-speed gaps, protected pedestrians/signals, and junction margin.
- Added deterministic next-tick reservation arbitration and private
  request/change-out/pass/return/cooldown runtime. Authored multi-lane queues no longer use
  the free-form compatibility pass maneuver.
- Rejected an unsafe graph prototype that represented lane changes as unowned long diagonal
  route edges. Dense QA proved those edges could converge cars on one node. Stable route
  lanes now remain separate from explicitly reserved physical maneuvers.
- Extended junctions from a fixed center radius to lane-derived conflict bounds. Stop lines
  are fixed from lane geometry, request lookahead includes braking distance, rear clearance
  projects the bounds onto travel direction, and terminal turnarounds are serialized
  synthetic junctions.
- Extended F3 traffic diagnostics with active changes, requests, completions, rejection
  reasons, reservations, and targets. The Three overlay draws the active trajectory and
  entry point.
- Kept the interaction-island boundary frozen. No prediction, reconciliation,
  interpolation, AOI, rewind, rollout, or shared movement/contact code changed.
