# Development log - 2026-07-23

## Vehicle durability and ambient traffic balance

- Reduced active civilian traffic around players by 25%: bootstrap traffic now targets 12 cars
  and streamed traffic caps at 18, down from 16 and 24.
- Restricted ambient civilian selection to Sedan and Taxi. The S15 and R33 remain valid catalog
  vehicles for authored, parked, mission, player-owned, or future special-purpose use.
- Added a centralized player-driven crash-damage policy. World and vehicle collision damage is
  halved while a player is driving; weapon, melee, fire, and explosion damage is unchanged.
- Kept undriven ambient vehicles on full collision damage so traffic cleanup and wreck behavior do
  not become artificially slow.
- QA: vehicle damage/controller tests, population profile/streaming tests, district population
  tests, the two-client multiplayer integration test, TypeScript, and `git diff --check` all pass.

## Industrial Arena race mode

- Added `/race` and the six-client `district-race` room as a separate authoritative game mode.
- Generated a 64x64-tile circuit from a bounded Industrial District crop. The race package owns
  its map, minimap, geometry chunks, collision map, and closed one-way lane graph under
  `public/assets/districts/raceway`.
- Added an authoritative race controller with assigned R33/S15 grid cars, five-second countdown,
  ordered checkpoint validation, three laps, positions, lap/best-lap timing, results, automatic
  heat reset, disconnect cleanup, and vehicle recovery.
- Added race-specific Three presentation: circuit assets, checkpoint ring and minimap marker,
  race HUD, runtime label, and suppression of street missions, services, traffic, pedestrians,
  pickups, signals, and ordinary vehicle-exit interaction.
- Generalized collision-map and lane-graph loading to accept a map package directory without
  changing the default district paths.
- Added `npm run map:generate-raceway` so the circuit package is reproducible from the local
  district source assets.
- QA: authoritative race lifecycle tests, TypeScript, production build, race package generation,
  collision/lane loading, and browser visual/runtime checks pass. The full suite had one
  timing-sensitive multiplayer integration failure in aggregate; that test passes in isolation.

## Raceway geometry refinement

- Expanded the custom raceway from a 2560x2560 compact course to a 2880x2880 circuit.
- Re-authored the centerline as a broad clockwise loop with long sweepers and removed the abrupt
  switchback-heavy shape.
- Changed race collision and road-mask resolution from 64 px to 40 px cells, reducing visible and
  physical stair-stepping at curved boundaries while continuing to use the existing tile atlas.
- Widened the course, moved the six-car grid onto the start straight, and expanded the authoritative
  checkpoint sequence from six to nine gates.
- Kept the arena traffic-free and regenerated all 81 streamed Three geometry chunks.
- QA: race map generation, drivable grid/checkpoint contract tests, race-room startup test,
  TypeScript, production build, preview inspection, and whitespace checks pass. The broad suite
  also ran 625 passing tests but retained two unrelated timing-sensitive multiplayer failures.
