# Pixel Guns demo assets

Source: [Pixel Guns (2D Weapon Pack)](https://datdev.itch.io/pixel-guns-2d-weapon-pack) by datDev.

Imported from the free demo pack on 2026-07-20. The pack's storefront license permits
use and modification in personal and commercial projects, but prohibits redistributing,
reselling, or repackaging the assets themselves. Credit is appreciated but not required.

Runtime mappings:

- `Beretta M9.png` -> `pistol.png`
- `MP5.png` -> `smg.png`
- `Benelli M3.png` -> `shotgun.png`

The runtime copies are flipped horizontally so their muzzles face right, matching the
game's held-weapon rendering convention.
